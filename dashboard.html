What this HTML version does

Guided payment review, optional browser speech, demo PIN and OTP, simulated identity approvals, and a one-time simulated debit.

Encryption uses browser Web Crypto AES-256-GCM when available. Keys stay in this page's memory.

Voice, face, device, reviewer and officer checks are presentation scenarios—not biometric or banking authentication. The PIN and OTP are visible demo values.

Differences from the Python program

This standalone file does not run local Whisper/Vosk, ECAPA/AASIST, ML-KEM, ML-DSA, WebAuthn, QKD or banking APIs. It has no backend, trusted remote identity, persistent ledger or real payment capability. Editing this page can bypass its demo controls.

Reloading resets the ₹50,000 demo balance, contacts, keys and receipts. Encrypted payment packets expire after 120 seconds. OTPs expire after 60 seconds.

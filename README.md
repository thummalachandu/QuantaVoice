# QuantaVoice
### Quantum-Safe Voice Authentication Architecture for Digital Banking

**QuantaVoice** is an independent research project exploring secure voice-authorized payment systems through speaker verification, audio anti-spoofing, device authentication, and post-quantum cryptography.

## Overview

QuantaVoice investigates whether voice-initiated payment authorization can be made more secure by combining multiple independent authentication mechanisms rather than relying on voice recognition alone.

## Key Features

- **Speaker Verification:** ECAPA-TDNN-based speaker identity verification.
- **Audio Anti-Spoofing:** AASIST-based detection research for replayed, synthesized, and manipulated speech.
- **Device Verification:** Additional authentication through registered devices.
- **Post-Quantum Cryptography:** Research into quantum-resistant cryptographic protection.
- **Transaction Review:** Simulated transaction confirmation and authorization workflow.
- **Security Audit Records:** Signed and encrypted records for security and traceability.
- **REST API Gateway:** Modular architecture with consent-handling mechanisms.

## Architecture

Voice Input → Speech Recognition → Command Parsing → Speaker Verification → Anti-Spoofing → Device Authentication → Transaction Review → Cryptographic Authorization → Simulated Payment → Audit Record

## Current Project Status

QuantaVoice is currently an experimental research prototype operating entirely in a simulated environment.

- No real money is transferred.
- No banking or payment network is connected.
- Authentication and payment workflows are simulated.
- Empirical speaker verification and anti-spoofing evaluations remain future research work.

## Research Objectives

- Investigate multi-layer voice authorization security.
- Study replay and synthetic voice attack resistance.
- Explore post-quantum cryptographic integration.
- Develop a modular and testable security architecture.
- Plan future evaluation using consented speech datasets.

## Disclaimer

QuantaVoice is an independent research prototype and is not a production banking or payment system.
